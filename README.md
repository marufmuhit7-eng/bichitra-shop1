# বিচিত্রা শপ (Phase 1)

সাবস্ক্রিপশনভিত্তিক মাল্টি-ভেন্ডর মার্কেটপ্লেস। এই ধাপে আছে: ডিজাইন সিস্টেম (লোগোর হলুদ #FFF300 ও মেরুন #890E4F), হোমপেজ, পণ্য তালিকা (সার্চ, ফিল্টার, সর্ট, পেজিনেশন), পণ্যের বিস্তারিত পেজ, বিক্রেতার প্ল্যান পেজ ও রেসপন্সিভ নেভিগেশন।

## কম্পিউটারে চালানোর নিয়ম (একবারের সেটআপ)

1. https://nodejs.org থেকে **Node.js (LTS)** ইনস্টল করুন।
2. ZIP ফাইলটি আনজিপ করুন।
3. Terminal (Windows-এ Command Prompt) খুলে ফোল্ডারে যান: `cd bichitra-shop`
4. `npm install` লিখে Enter চাপুন (ইন্টারনেট লাগবে, কয়েক মিনিট সময় নেবে)।
5. `npm run dev` লিখুন।
6. ব্রাউজারে http://localhost:3000 খুলুন।

প্রথমবার ফন্ট ডাউনলোডের জন্য ইন্টারনেট দরকার।

## এই ধাপের সীমাবদ্ধতা (ইচ্ছাকৃত)

- পণ্য, বিক্রেতা ও রেটিং **নমুনা ডেটা** (`lib/sample-data.ts`)। Phase 2-এ Supabase ডাটাবেস দিয়ে বদলানো হবে।
- কার্ট, উইশলিস্ট, লগইন ও বিক্রেতা আবেদন বাটন বন্ধ (disabled) আছে। এগুলো পরের ধাপে চালু হবে।
- পণ্যের ছবি এখন ইমোজি-প্লেসহোল্ডার। আসল ছবি আপলোড Phase 3-এ।

## ফোল্ডার পরিচিতি

- `app/` : পেজগুলো (হোম, `products`, `sell`)
- `components/` : হেডার, ফুটার, প্রোডাক্ট কার্ড ইত্যাদি
- `lib/` : ডেটা, দামের ফরম্যাট (৳, বাংলা সংখ্যা), প্ল্যান
- `tailwind.config.ts` : ব্র্যান্ডের রঙ ও ফন্ট
